# Своя Игра (Own Game / Jeopardy)

Интерактивное веб-приложение для проведения викторины в стиле «Своя Игра» / «Jeopardy!», разработанное на **React** и **Vite**.

Приложение позволяет проводить интеллектуальные викторины для команд или индивидуальных участников, а также с легкостью создавать, редактировать, импортировать и экспортировать собственные наборы вопросов.

---

## 🚀 Основные возможности

- **Игровой процесс:**
  - Интерактивное игровое табло с категориями и ценой вопросов.
  - Поддержка табло очков для 3 команд (с возможностью изменения названий команд).
  - Режим просмотра вопроса с таймером ответа, скрытием/раскрытием ответа и кнопками начисления/списания баллов.
  - Поддержка медиаконтента (картинки и аудиофайлы в вопросах).
  - Сохранение текущей игровой сессии (`sessionStorage`): при случайном обновлении страницы прогресс не теряется.

- **Встроенный редактор игр (`Game Editor`):**
  - Создание и редактирование тем, вопросов, ответов, стоимости и медиафайлов.
  - Настройка цветовых тем оформления (фон игрового поля, шапка, акцентные цвета).
  - Экспорт и импорт наборов вопросов в формате JSON.
  - Поделиться игрой по ссылке (упаковка конфигурации игры прямо в URL-хэш).

## 💻 Установка и запуск

### Требования
Для работы с проектом требуется установленный [Node.js](https://nodejs.org/) (версии 18+).

### Инструкция по запуску

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/arslankhisamutdinov/own-game.git
   cd own-game
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите режим разработки:**
   ```bash
   npm run dev
   ```
   Приложение станет доступно по адресу `http://localhost:5173`.

---

## 📜 Скрипты

- `npm run dev` — Запуск локального сервера разработки.
- `npm run build` — Сборка проекта для продакшена в папку `dist`.
- `npm run preview` — Предпросмотр собранной продакшн-версии.
- `npm run lint` — Проверка кода с помощью ESLint.
